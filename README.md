# Avto Skaner

Wi-Fi va Bluetooth ELM327 orqali mashinani tekshiradigan Android ilova.

- Xato kodlari (saqlangan, kutilayotgan, doimiy) o'zbekcha izoh bilan
- Freeze frame, tayyorlik monitorlari, 17 ta datchik
- Jonli rejim: taxometr, spidometr, grafiklar, yoqilg'i sarfi
- 0–100 km/soat sinovi
- Tekshiruvlar tarixi, PDF hisobot, AI ga yuborish
- Garaj: mashina profili, moy, sug'urta, texnik ko'rik eslatmalari

APK har push'da GitHub Actions orqali yig'iladi va Releases bo'limiga qo'yiladi.

Litsenziyalar: Manrope va Orbitron shriftlari (SIL OFL 1.1), 3D ikonkalar Microsoft Fluent Emoji (MIT).
